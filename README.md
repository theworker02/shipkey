# shipkey

Ship HTML/Markdown key fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/shipkey/

## Install / run

```bash
git clone https://github.com/theworker02/shipkey.git
cd shipkey
node src/cli.js
node --test
```
